# Проверка поведения v6.8

1. Режим «Дополнять по пробелу»: набрать `прог`, выбрать `программа`, нажать Space. Ожидается `программа `.
2. В том же режиме набрать `прог` и нажать Shift+Space. Ожидается `прог `.
3. В режиме по пробелу нажать и отпустить Shift отдельно. Слово и список не должны отменяться.
4. Включить «Только обучение». При наборе слов список не должен появляться, `Tab` и Space должны работать как обычно.
5. Несколько раз набрать в обучении фразу `моя программа работает стабильно`, затем вернуться к списку. После `моя прог` персональный вариант должен получить высокий приоритет.
6. Несколько раз набрать одинаковую конструкцию из пяти слов. Следующее слово должно ранжироваться выше в том же контексте.
7. Набрать новое склоняемое слово в обучении. После завершения слова морфологический индекс должен обновиться без перезапуска.
8. Переключить профиль: обучение одного профиля не должно влиять на другой.
9. Импортировать текстовый файл. Счётчики слов и контекстов должны увеличиться, а связи не должны переходить через точку или перенос строки.
10. После обновления поверх старой папки существующий JSON-профиль должен открыться без сброса.
